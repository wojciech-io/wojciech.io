# Prompt 02 - Claude / Claude Design exploration

Create three visual directions for a premium personal site for a senior growth/GTM operator.

Context:

- The site is `wojciech.io v2`.
- It should combine the darker technical system feeling of `app.wojciech.io` with the proof-led narrative clarity of `brand24-ai.vercel.app`.
- It should feel editorial, premium, precise and built by an operator.
- Avoid generic SaaS gradients, agency cliches and overly decorative motion.

Please produce:

1. one conservative direction,
2. one more technical / system-like direction,
3. one more editorial / founder-led direction.

For each, define:

- palette approach,
- typography mood,
- hero composition,
- section rhythm,
- proof-card styling,
- interaction style,
- why it fits or does not fit Wojciech's positioning.

Do not create finished copy. Focus on visual grammar and layout logic.
