## Homepage recommended section logic

1. **Hero**
   - current positioning in one sentence
   - clear audience / problem
   - two CTAs: work and meeting

2. **Problem framing**
   - growth often breaks because systems are fragmented, not because teams lack activity

3. **How I work**
   - diagnose revenue architecture
   - design the system
   - implement / instrument / iterate
   - build missing tools when needed

4. **Proof architecture**
   - AI-native GTM systems
   - Growth architecture in practice
   - Products actually shipped

5. **Selected work**
   - 3 flagship proof cards / case narratives

6. **AI systems / operating leverage**
   - how AI changes the way Wojciech works, not a generic AI page teaser

7. **Testimonials**
   - curated subset, all retained in inventory

8. **Insights / article**
   - Claude Code starter pack as anchor

9. **Final CTA**

## Why this IA is stronger

- It maps to the current career story.
- It does not compete with `app.wojciech.io`; it routes to it intentionally.
- It balances consulting credibility with builder proof.
- It is extensible without becoming a generic services site.
