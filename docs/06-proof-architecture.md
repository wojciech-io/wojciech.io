## Metrics strategy

Do **not** reuse old numbers blindly. Build a new metrics stack after validation.

### Candidate metric families

1. **Revenue impact**
   - MRR growth
   - revenue uplift
   - SQL / pipeline impact

2. **Operating depth**
   - years in B2B SaaS / growth
   - number of systems built or domains led
   - speaking / workshops if still strategically useful

3. **Builder proof**
   - number of shipped products / apps
   - number of live tools / apps in portfolio
   - possibly number of AI workflows / operator tools created

### Rule

Every public metric must be:

- defensible,
- specific enough to mean something,
- relevant to the audience,
- better than a vague vanity number.
