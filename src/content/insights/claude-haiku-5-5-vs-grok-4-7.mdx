Claude Haiku 5.5 is the smallest model in Anthropic's lineup. On Artificial Analysis Intelligence Index v5.0 it scores one point above Grok 4.7, and running the index cost a fifteenth as much.

Haiku's list price is a twentieth of Grok's on input and a twelfth on output. Past 100,000 prompt tokens it rises to $0.50 and $2.50, which is still a quarter of Grok's input price and 42% of its output price.

Haiku at high scores one point below Grok at low and costs $0.16 against $2.92, eighteen times less. Grok's top setting is not its best. Xhigh costs $1.33 more a task than high and scores a point lower, so on this run more effort bought a bigger bill and a worse result.

## Both models talk a lot

Haiku generated 300 million tokens on the index. Grok at xhigh generated 140 million, against a median near 70 million. Verbosity flatters a per-token price, because the job costs more than the sticker suggests, and that makes the per-task row the one to read. Haiku still wins it by a wide margin.

## Where Grok 4.7 still has a case

Not on the score. It has the smaller context window, the higher price, and a place below the average of comparable models on the index.

What it has is the ecosystem around it. The xAI API offers server-side tools for web search, X search and code execution. Grok Build is xAI's terminal coding agent, in beta since May. Grok Bot runs saved routines in the cloud, which I cover in [what stops your agent](/insights/autonomous-ai-agents-compared/). If your work lives on X, or you already pay for SuperGrok, that is a reason. Grok 4.7 Fast, at twice the token rates, is only available in Cursor and Grok Build.

## Which one I would use

For classification, extraction and routing, Haiku 5.5, which is what Anthropic built it for. Test it on a hundred of your own examples first, because one index is one index.

For a workload that needs X search, or a team already inside Grok Build, Grok 4.7. For everything else I would need a reason to pay fifteen times as much per task for a point less.

## What would change my mind

A task where Haiku's verbosity bites: long outputs billed at $0.50 per million still add up at 300 million tokens. A second index run that moves either score by more than a point. And any pricing change on Grok 4.7, which lists at the same $2 / $6 that Grok 4.6 did in August.
