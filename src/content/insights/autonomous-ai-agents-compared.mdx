Every large lab now sells you an agent you can leave running. Read five sets of documentation side by side and the loop is the same in all of them: wake up, act, check, go back to sleep.

What differs is what wakes it, where it runs, what stops it and who pays. The launch posts cover the first one. The other three sit lower in the docs, and that is where the bill and the damage are.

<Callout type="note" title="What this piece is">
  Nothing here is a benchmark run. It is each vendor's own documentation and changelog, read side by side on 1 November 2026, with the sentence that carries each limit kept in the sources. Several of these products are in preview or private beta, so check the page before you rely on a number.
</Callout>

A ChatGPT task can use several event triggers but cannot combine them with a schedule, so "every morning, and also when the client emails" is two tasks. A Claude cloud task cannot see your local files, because it starts from a fresh clone. Anything that needs your disk belongs on your machine, and your machine has to stay on. Those details decide more than the logos do.

## What stops it is the part nobody puts on the launch page

A forgotten agent is a cost and a risk. So the useful column is not what starts a run, it is what ends one you stopped thinking about.

Read the last row twice. In Hercules the cap is a blank field, and the docs say plainly that leaving it empty means no limit. In Claude Code the loop ends itself after a week, and the docs give the reason: it bounds how long a forgotten loop can run. Nobody else in this set built a stop that works without you remembering to configure it.

Grok's number deserves its own sentence. 300 runs an hour is a speed limit. It stops a runaway in minutes and does nothing about a slow leak: a routine that is wrong 200 times an hour for a day is 4,800 wrong runs inside the limit.

## Who pays for each run

Money is where the five diverge most, and the docs are least precise about it.

- **Claude cloud tasks** draw subscription usage "the same way interactive sessions do". With usage credits switched on they can keep running on metered overage. Without them extra runs are rejected until the window resets.
- **ChatGPT dots**: conversations with your dot do not count toward ChatGPT usage limits. Tasks it starts in Work or Codex do.
- **Grok Bot**: every run spends usage, so a routine that fires often costs more than one that fires rarely, and there is a weekly limit and a monthly on-demand one.
- **Gemini**: pay as you go on tokens and tool use. Google puts a typical task at $0.25 to $3.25 and a heavy workflow at 3 to 5 million tokens, roughly $5. Sandbox compute is not billed during the preview.
- **Hercules**: AI credits, the same pool as the app builder. Guardrail checks, scoring and Auto-improve draw from it too.

## Radar: Hercules, Grok Bot and a repo with 109,000 stars

These are the ones people share in group chats. Here is what the documentation says, without the thread.

**Hercules** is two products. The App Builder is a chat-driven builder whose agent can read and write a codebase, search the web, generate images and control a browser to test its own changes. Hercules Agents are the other half: workers you describe once and leave running, in private beta, enabled per organisation. What stands out is the tooling around a run. Every run is recorded, you can mark runs good or bad, turn a run into a test case, score runs, and let Auto-improve read the history and suggest fixes under a credit cap. It is the only one of the five whose docs describe an evaluation loop shipped with the agent. It is also the one whose default is no spend limit.

**Grok Bot** treats a successful task as something to freeze. Skills are saved instructions, routines say when to run them. The ceilings are generous and the safety advice is in prose: keep write actions behind approval, use narrow triggers, test before enabling. All of that is guidance you have to follow, not a switch you flip.

**Paperclip** is an MIT-licensed repository with more than 109,000 GitHub stars when I looked. Its README calls it a Node.js server and React UI that "orchestrates a team of AI agents to run a business", with org charts, tasks, budgets and approvals, and it drives runtimes such as Claude Code, Codex, Cursor and Gemini CLI. Budgets can be set per company, agent and project, and work pauses at the configured limit. That is the leash as a product, one level above the vendors. I read the README and did not run it. Telemetry is on by default and has to be switched off with an environment variable, so try it in a throwaway container, not on the machine that holds your keys. For one person with three scheduled jobs it is a lot of company. For someone running Claude Code and Codex side by side it is worth reading for the budget and approval design even if you never install it.

## Which one I would use

If the job only reads, any of them. If it writes, sends or spends, I would start from the leash, not from the logo.

1. Run it as a `/loop` for a week. It expires on its own, so a mistake has a deadline.
2. If the log is boring after a week, promote it to a cloud task, and keep write actions behind the approval mode.
3. If it runs through the API, set the session budget on day one. A hard cap is the only stop that does not depend on a person.
4. If you pick Hercules, fill in the spend and time fields before the first run, and read the history after the first ten.

## What would change my mind

Gemini shipping a scheduler or event triggers would put it in the same table as the rest. OpenAI publishing numeric limits for scheduled tasks would fix the one column where it is vaguest. Hercules defaulting to a cap instead of a blank would remove my main objection. Docs here change monthly, and I re-check the quoted lines against the live pages on a schedule.

## Questions people asked

### Can an AI agent keep working while my laptop is off?

Yes, if it runs in the vendor's cloud: Claude cloud scheduled tasks, Grok Bot routines, ChatGPT web tasks and dots. No, if it runs on your machine: Claude Code `/loop`, Claude Code Desktop tasks and ChatGPT desktop tasks that need local files.

### Which AI agent has a hard spending cap?

Claude Managed Agents has a per-session budget that is a hard cap priced at list rates, and Hercules has a per-run spend limit. In Hercules the field is empty by default, which means no limit. Gemini's `max_total_tokens` on the Antigravity agent is best effort and can be slightly exceeded.

### What is Hercules?

Two products under one name: an AI app builder, and Hercules Agents, which are AI workers you set up once and leave running. Agents are in private beta, start from a schedule, events in connected apps or a Slack message, and use the same AI credits as the builder.

### What is Grok Bot?

xAI's agent that runs saved skills and routines. A routine runs in the cloud while your laptop is closed, on a schedule at least five minutes apart or from events in Slack, GitHub, Linear, Sentry, PagerDuty, email or a webhook.

### Is Paperclip worth installing?

It is an MIT-licensed control plane that puts budgets, approvals and an audit log above a team of agents such as Claude Code and Codex. I read the README and did not run it. Telemetry is on by default, so test it in a throwaway container.
