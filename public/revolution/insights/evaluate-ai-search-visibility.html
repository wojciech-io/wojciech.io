Measure AI search visibility with repeatable questions

The useful question is whether a buyer can find a supported answer for a task they need to finish. Ask the same questions every time.

Wojciech Luszczynski2 min read

Three questions, three buyer intents: compare, how to, pricing. The wording stays fixed between runs.

Fix the questions and the baseline

I pick a small set of questions with different buyer intent. For each one I record the wording, the conditions of the run and what counts as a mention, a usable link or a correct citation. That record stays apart from the usual search and conversion reports.

Make each page worth citing

Each page answers one question, opens concisely and gives evidence the reader can check. The facts agree with the rest of the site. Structured data describes only what is visible. I test that the public page and its canonical destination can be retrieved.

Same questions, same conditions, every run.

Repeat the scan and keep the raw answers

Answers vary between runs. I track the query, the context of the answer and the cited destination in comparable batches. A change in mentions is read together with answer accuracy, referrals and the measurable next step on the site.

Use the evidence to choose a change

If several answers miss a documented capability, I check whether the page is discoverable and explicit. I fix the answer on the page, run the same questions again and record the conditions. The next editorial change then starts from recorded answers.
