01 Problem

Enquiries arrive with a clear request and missing details on timing, fit or the next decision. Sales cannot answer well without a brief.

02 Solution

Facts first,then a reply

An agent that collects the missing details and prepares a structured handoff and a proposed reply for a reviewer.

03 Implementation

How itis built

The app takes an enquiry, logs the facts it can support and puts a draft in a review queue. This began as a take-home exercise. I wrote scenario tests that run against a model substitute, and I recorded a live-model check separately.

  • Python
  • FastAPI
  • React
  • LLM evaluation

Review step checklist

  1. Start with one job you can undo
  2. Show the original request next to the draft
  3. Keep what was said apart from what the model inferred
  4. Tie approval to one version and one destination
  5. Check permissions at the write step
