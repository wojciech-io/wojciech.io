    01 Problem

    Campaign cost, web activity and CRM records used different labels and different periods. Seeing which segments produced demand meant manual reconciliation.

    02 Solution

    Aligned snapshots,one view

    A dashboard that reads from aligned snapshots. You start at the topline and drop into a segment or an acquisition source.

    03 Implementation

    How itis built

    The data layer cleans up the source records first. Only then does the interface work out spend per lead. Follow-up items arrive apart from the performance metrics. The demo adds a source freshness view, so you can see what a late feed does to a number.
