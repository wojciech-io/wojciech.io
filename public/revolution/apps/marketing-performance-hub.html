    Problem

    Campaign cost, web activity and CRM records used different labels and different periods. Seeing which segments produced demand meant manual reconciliation.

    Solution

    Aligned snapshots, one view

    A dashboard that reads from aligned snapshots. You start at the topline and drop into a segment or an acquisition source.

    How a number gets here

    Clean
    The data layer cleans up the source records first.
    Divide
    Then the interface calculates spend per lead.
    Show
    A source freshness view shows what a late feed does to a number.

    Follow-up items arrive apart from the performance metrics.

    Result

    Spend and demand sit in one view. When a feed is late, the number says so.

    The documentation I have shows it in use. Spend and lead counts in the demo are made up.
